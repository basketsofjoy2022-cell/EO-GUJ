# EO Gujarat - GST Declaration Form

Online declaration form for Entrepreneurs Organisation (Gujarat) members.

## What it does
- Member fills the declaration (name, parent name, address, company, date, place)
- Signs by drawing (mouse / touch) or uploading a signature image
- On submit, a signed PDF is generated, a copy downloads to the member's device, and the form plus PDF are emailed to eogujarat@gmail.com via FormSubmit

## Setup note
The first submission triggers a one-time activation email to eogujarat@gmail.com. Click "Activate" in that email once. All later submissions arrive automatically.

## Files
- `index.html` - the complete form (single file, no build needed)
